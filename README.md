# משחק לוח הכפל — משתלת ביצי הדרקון

הגרסה העברית של [Dragon Egg Nursery](https://github.com/aloneden/times-tables-game): משחק כיפי שעוזר לילדים ללמוד את לוח הכפל.

- בונים קנים (שורות × ביצים), מקלפים ביצים ומקבלים דרקונים, ופותחים לוחות כפל במפה.
- קרב זומבים (אופציונלי): לכל דרקון התקפה משלו, ובכל שלב חדש מגיעים זומבים חזקים יותר.
- HTML/CSS/JavaScript בלבד, בלי build. פותחים את `index.html` בדפדפן.
